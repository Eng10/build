# Build Ledger — سجل البناء

تطبيق ويب (يعمل على الآيفون والأندرويد والكمبيوتر) لمتابعة مصاريف بناء البيت: مشاريع متعددة منفصلة، مراحل وبنود ودفعات،
مقاولون وعقود PDF، تقارير، تحديثات وصور الموقع، وملاحظات بمحادثة لكل صورة. البيانات تُحفظ في قاعدة بيانات سحابية
(Supabase / PostgreSQL) وتتزامن لحظياً بين كل الأجهزة المصرّح لها. الصلاحيات تُفرض داخل قاعدة البيانات نفسها وليس في الواجهة فقط.

## نظام الدخول والصلاحيات

- الدخول بالبريد وكلمة المرور (Supabase Auth). عند التسجيل يُنشأ ملف شخصي: الاسم + **اسم المستخدم** + الجوال (اختياري).
- لا يظهر أي مشروع أو بيانات قبل تسجيل الدخول، وقاعدة البيانات ترفض أي طلب بلا جلسة.
- كل مشروع له فريقه المنفصل. أدوار المشروع: **مسؤول (admin)** و**مشرف (supervisor)** و**مستخدم (user)**،
  ويقدر المسؤول تعديل أربع صلاحيات لأي عضو: 💰 رؤية المبالغ، ✎ الإضافة والتعديل والحذف، 📷 مساحة الزيارات والملاحظات، 👥 إدارة الأعضاء.
- الدعوة بالجوال أو اليوزر: يصل للمدعو طلب انضمام يقبله أو يرفضه. الدور الافتراضي للمدعو «مستخدم» (اطلاع على التكاليف فقط)،
  وبعدها يرقّيه المسؤول لمشرف أو يعدّل صلاحياته (مثل واتساب).
- من لا يملك صلاحية المبالغ تُحجب عنه الأرقام في قاعدة البيانات نفسها (عبر عروض `v_*`)، ولا يستطيع قراءة الدفعات ولا الحوالات ولا قيمة العقود.
  يمكن ربط حساب بمقاول معيّن فيرى المقاول عقده فقط.
- صاحب المشروع لا يمكن إزالته أو خفض صلاحياته، وفقط هو من يمنح دور المسؤول وصلاحية إدارة الأعضاء.

## التشغيل محلياً في VS Code

المتطلبات: Node.js 18 أو أحدث، وحساب مجاني على supabase.com.

1. افتح المجلد في VS Code: `File > Open Folder` ثم اختر `build-ledger`، وافتح Terminal.
2. `npm install`
3. أنشئ مشروعاً في Supabase (انظر الخطوات التالية) ثم انسخ `.env.example` إلى `.env` وضع قيمك.
4. `npm run dev` ثم افتح الرابط الذي يظهر (غالباً http://localhost:5173). من الجوال على نفس الشبكة استخدم عنوان Network الظاهر في الـ Terminal.
5. `npm test` لتشغيل الاختبارات، و`npm run build` لإخراج نسخة الإنتاج في `dist/`.

## ربط قاعدة البيانات (Supabase) خطوة بخطوة

1. في supabase.com اضغط **New project**، اختر الاسم وكلمة مرور قاعدة البيانات والمنطقة الأقرب لك.
2. من **SQL Editor > New query** الصق محتوى `supabase/migrations/001_schema.sql` كاملاً واضغط **Run** (مرة واحدة فقط).
   ينشئ الجداول والصلاحيات والتخزين الخاص (أربع حاويات: receipts, contracts, updates, visits) وقناة المزامنة اللحظية.
3. من **Project Settings > API** انسخ `Project URL` و `anon public key` إلى ملف `.env`:
   ```
   VITE_SUPABASE_URL=https://xxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJ...
   ```
   لا تضع مفتاح `service_role` في التطبيق إطلاقاً.
4. من **Authentication > Providers > Email** اترك تأكيد البريد مفعّلاً للإنتاج، وأعدّ SMTP خاصاً بك من **Authentication > SMTP** (خدمة Supabase المدمجة محدودة العدد).
5. من **Authentication > URL Configuration** ضع رابط موقعك في `Site URL` (و`http://localhost:5173` في Redirect URLs أثناء التطوير) ليعمل رابط استرجاع كلمة المرور.
6. اختبر: سجّل حساباً، أنشئ مشروعاً، افتح التطبيق على جهاز ثانٍ بحساب آخر وادعُه من «فريق المشروع»، وراقب ظهور التغييرات لحظياً.
7. اختياري: لتنبيه الدفعات المجدولة يومياً فعّل إضافة `pg_cron` من **Database > Extensions** ثم شغّل السطر الموجود معلّقاً في آخر ملف SQL.

## النشر

ارفع مجلد المشروع إلى GitHub ثم اربطه بـ Vercel أو Netlify أو Cloudflare Pages: أمر البناء `npm run build` ومجلد الإخراج `dist`،
وأضف المتغيرين `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` في إعدادات المنصة. يُنصح بإضافة ترويسات أمان من المنصة،
مثل Content-Security-Policy تسمح بـ `connect-src 'self' https://*.supabase.co wss://*.supabase.co` و`img-src 'self' blob: https://*.supabase.co`.
على الآيفون: افتح الرابط في Safari ثم «إضافة إلى الشاشة الرئيسية».

## ملاحظات صريحة

- ملف SQL لم يُشغَّل على قاعدة Postgres حقيقية أثناء التطوير (لا تتوفر في بيئة الكتابة). فُحص بنيوياً فقط. شغّله على مشروع Supabase تجريبي أولاً، وإن ظهر خطأ في سطر معيّن أرسله لتصحيحه.
- المتحكّم `src/app.js` والاتصال الفعلي بـ Supabase والمزامنة اللحظية لم تُجرَّب على خادم حقيقي؛ المختبَر آلياً هو المنطق والصلاحيات وكل الشاشات (باللغتين وكل الأدوار) وربط الوحدات.
- تسجيل الدخول بالبريد. الدخول برقم الجوال برمز SMS يحتاج مزوّد رسائل مدفوعاً في Supabase.
- لا يوجد وضع عمل بدون إنترنت؛ التطبيق يحتاج اتصالاً.
- التنبيهات داخل التطبيق (جرس الإشعارات). إشعارات الجوال الفورية تحتاج تطبيقاً أصلياً أو Web Push، وهي خارج هذه النسخة.
- لم تُنقل ميزة «المواعيد والتنبيهات» اليدوية من النسخة التجريبية؛ حلّ محلها جدولة الدفعات (حالة «مجدولة» وتاريخ استحقاق) مع تنبيه تلقائي.
